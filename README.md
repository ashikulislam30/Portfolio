# Portfolio Website

A modern, dark-themed portfolio website built with React, Vite, Tailwind CSS, and Framer Motion for smooth animations.

## Features

- **Hero Section** – Introduction with profile, tech stack tags, and CTA buttons
- **Featured Experience** – Work history with company logos, roles, and technologies
- **Technologies** – Skills and tech stack display
- **Featured Projects** – Project cards with images and descriptions
- **Featured Blogs** – Blog post cards with tags and dates
- **About Me** – Bio with skills
- **GitHub Activity** – Contribution graph visualization
- **Development Setup** – Gears Used and VS Code setup links
- **Quote Section** – Inspirational quote
- **Call to Action** – Book a Free Call
- **Floating Action Button** – Contact/chat shortcut
- **Dark/Light Mode Toggle** – Theme switching

## Tech Stack

- React 19
- Vite 7
- Tailwind CSS 4
- Framer Motion

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

Open [https://www.ashikulislam.me/](https://www.ashikulislam.me/) to view the portfolio.

## Build

```bash
npm run build
```

## Customization

- Update `src/components/Hero.jsx` for your name, title, and links
- Edit `src/components/FeaturedExperience.jsx` for work history
- Modify `src/components/FeaturedProjects.jsx` and `FeaturedBlogs.jsx` for projects and blog posts
- Replace placeholder avatars (ui-avatars.com) with your own images
